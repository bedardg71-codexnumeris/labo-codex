## §2 · Interface (iPad, Safari)

### 2.1 Le PDF d'un·e étudiant·e s'ouvre dans un nouvel onglet (G5)

┌ POURQUOI ─────────────────────────────────────────────────────────────
│ Sous Safari, un onglet ouvert hors du geste est bloqué. L'onglet est donc ouvert vide, au toucher, puis il reçoit le
│ PDF quand il est prêt. Chromium le montre au banc ; Safari sur l'iPad, lui, n'existe pas dans le conteneur : seul
│ l'iPad peut dire si l'onglet s'ouvre, si le PDF y paraît, et si l'application reste dans le sien.
└──────────────────────────────────────────────────────────────────────

  dessine DANS le champ vide (rien, ou « jj/mm/aaaa ») n'est pas mesuré.
