Critères de choix pour le bleu Évaluation :

4. Comparatif blend modes — fond du bouton actif (Conception orange)

Quatre approches comparées sur le même bouton actif. Basculez le thème pour vérifier dans les deux fonds.

Conception
A — alpha 0.10 (référence)
rgba(255,111,0,0.10)
Translucide. Voilé.
Conception
B — mix-blend-mode: multiply
Fond orange opaque + multiply.
Affecte icône + texte aussi.
Conception
C — background-blend-mode: multiply
2 couches BG mixées.
N'affecte ni icône ni texte.
Conception
D — mix-blend-mode: color
Garde luminance du fond,
applique teinte. Affecte tout.

Notes attendues :
• A = ce que vous voyez actuellement (voile subtil).
• B = fond plus marqué mais l'icône blanche risque de s'estomper (multiply avec blanc = inchangé visuellement, mais avec couleur en dessous → assombrissement).
• C = fond plein clairement teinté, icône et texte intacts. Probablement le meilleur compromis.
• D = teinte appliquée uniformément en gardant la luminance — effet « passé à l'orange » sur le bouton entier.

5. Boutons header (aide + réglages) — état actif teinté jaune

Même traitement que pour la nav : quand l'utilisateur ouvre la section Aide ou Réglages, le bouton concerné reçoit fond teinté jaune + bordure jaune. L'icône reste jaune dans les trois états. Bug, anonymisation et thème restent neutres (boutons d'action, pas de section).

État au repos (aucun actif) — icône jaune permanente
Aide active — fond teinté + bordure jaunes
