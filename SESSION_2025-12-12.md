### BETA 94 - SYSTÈME DE SNAPSHOTS HEBDOMADAIRES

#### Session 1 (10 décembre 2025)

**Implémentation complète du système de snapshots**

**Nouveau module** : `js/snapshots.js` (765 lignes)

**Fonctionnalités** :
- Capture automatique à chaque saisie de présences
- Données capturées : A ponctuel, A_cumulatif, C, P, pattern, niveau RàI
- Reconstruction rétroactive de tous les snapshots historiques
- Graphiques Chart.js pour visualisation évolution

**Distinction ponctuel vs cumulatif** :

| Graphique | A | C | P | Rationale |
|-----------|---|---|---|-----------|
| **Individuel** | Cumulatif | Cumulatif | Cumulatif | Dépistage impact à long terme |
| **Groupe** | Ponctuel | Ponctuel | Cumulatif | Détection variations récentes |

**Rationale pédagogique** :
Les indices cumulatifs (graphique individuel) permettent de mieux dépister l'impact à long terme d'une absence ou d'un travail non remis sur l'apprentissage. Les indices ponctuals (graphique groupe) permettent de détecter rapidement les problèmes émergents (séance difficile, échéance problématique).

**Structure des données** :
```javascript
{
    id: "snapshot-2025-09-03",
    dateSeance: "2025-09-03",
    numSemaine: 1,
    etudiants: [
        {
            da: "9000116",
            nom: "Eve B.",
            A: 100,              // Ponctuel (graphique groupe)
            A_cumulatif: 100,    // Cumulatif (graphique individuel)
            C: 67,               // Cumulatif
            P: 75.5,             // Cumulatif
            pattern: "stable",
            rai: 1
        }
    ]
}
```

### BETA 93.5 - ARCHITECTURE MULTI-COURS ET GROUPE DÉMO

#### Développement (11 décembre 2025)

**Objectif** : Préparer architecture pour supporter plusieurs cours-groupes simultanément et intégrer groupe démo préchargé.

**Hiérarchie pédagogique** :
```
TRIMESTRE (H2026, A2025, etc.)
    ↓
COURS (601-101, 601-102, 601-103)
    ↓
GROUPE (01, 02, 03, 9999)
    ↓
ÉTUDIANTS + DONNÉES
```

**Modifications structures de données** :
1. **Cours** → Ajout `trimestreId`
2. **Étudiants** → Ajout `coursId`
3. **Productions** → Ajout `coursId`
4. **Présences** → Ajout `coursId` (via migration)

**Nouveau module** : `js/migrations.js` (189 lignes)
- 4 migrations automatiques Beta 93.5
- Exécution transparente au chargement

**Groupe démo préchargé** :

**Interface utilisateur** :
- Emplacement : Réglages → Trimestre → "Données de démonstration"
- Contrôle : Checkbox "Utiliser les données de démonstration (groupe 9999)"
- Fonction : `basculerDonneesDemo(activer)` dans trimestre.js

**Contenu du groupe 9999** :
- Trimestre : H2026 (fictif)
- Cours : 601-101 Écriture et littérature
- Enseignant : Primo Primavera
- 10 étudiants fictifs (DA 2234567-2234576)
- 4 artefacts avec échéances
- 40 évaluations complètes (notes IDME)
- 8 semaines présences (92% assiduité moyenne)

**Fichier source** : `pack-demarrage-complet.json` (99 KB)
**Module chargeur** : `js/pack-demarrage.js` (converti en JavaScript)

**Fonctionnement** :
```
Activation (checkbox cochée)
    ↓
Fusion intelligente avec données existantes
    ↓
Cours demo ajouté + 10 étudiants + 4 productions + 40 évaluations
Présences générées dynamiquement (pattern 92%)
    ↓
Groupe 9999 immédiatement disponible

Désactivation (checkbox décochée)
    ↓
Suppression propre de toutes données groupe 9999
    ↓
Application revient à l'état sans demo
```

**Bénéfices** :
- ✅ Architecture évolutive (prêt pour support multi-cours Beta 95+)
- ✅ Isolation claire des données par cours-groupe
- ✅ Nouveaux utilisateurs peuvent explorer avec données réalistes
- ✅ Suppression propre en un clic
