3. Boutons

Les boutons suivent une hiérarchie claire basée sur leur fonction. Chaque type a une couleur dédiée.

Types de boutons par fonction

Utilisez le bon type de bouton selon l'action Ã  effectuer.

Exemples visuels (survolez-les)
📋 Règles d'utilisation
  • btn-principal: Action principale de la page/section (Sauvegarder, Valider, Exporter)
  • btn-ajouter: Création de nouvelles entrées (Ajouter étudiant, Nouvelle production)
  • btn-modifier: Édition d'éléments existants (Modifier, Éditer)
  • btn-annuler: Annulation, réinitialisation (Annuler, Réinitialiser, Retour)
  • btn-supprimer: Suppression définitive (Supprimer - toujours demander confirmation)
Code HTML
<button class="btn btn-principal">Sauvegarder</button> <button class="btn btn-ajouter">Ajouter</button> <button class="btn btn-modifier">Modifier</button> <button class="btn btn-annuler">Annuler</button> <button class="btn btn-supprimer">Supprimer</button>

Tailles de boutons

Les boutons s'adaptent automatiquement selon leur contexte. Utilisez les modificateurs de taille pour des cas spécifiques.

ðŸ“ Dimensions
  • Large: 12px 24px - Actions très importantes
  • Standard: 10px 20px - Boutons hors contexte
  • Compact: 6px 12px - Boutons dans cartes/listes (appliqué automatiquement)
  • Très compact: 4px 10px - Espaces restreints
Code HTML
<button class="btn btn-principal btn-large">Large</button> <button class="btn btn-principal">Standard</button> <button class="btn btn-principal btn-compact">Compact</button> <button class="btn btn-principal btn-tres-compact">Très compact</button>

⚠️ Règle automatique importante

Les boutons DANS les contextes suivants sont automatiquement compacts (6px 12px) :

Contextes avec taille automatique
  • Boutons dans .carte
  • Boutons dans #listeCriteres
  • Boutons dans éléments avec ID contenant "liste" ou "tableau"
  • Boutons dans divs avec background: white ou var(--bleu-tres-pale)
