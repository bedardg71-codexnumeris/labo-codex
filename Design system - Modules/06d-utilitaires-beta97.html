1. Classe utilitaire .u-hide

Depuis la Beta 97.1, toute manipulation de visibilite passe par la classe CSS .u-hide au lieu de .style.display. Cette classe est definie dans styles.css ligne 343.

Definition CSS

.u-hide { display: none !important; }
Regles
  • !important garantit la priorite sur tout style inline residuel
  • Fonctionne avec tous les types d'affichage (block, flex, inline-block, etc.)
  • L'element retrouve son display naturel quand la classe est retiree

Exemples d'utilisation

FAIRE
// Cacher un element
element.classList.add('u-hide');

// Montrer un element
element.classList.remove('u-hide');

// Verifier la visibilite
if (!element.classList.contains('u-hide')) {
    // l'element est visible
}
NE PAS FAIRE
// INTERDIT depuis Beta 97.1
element.style.display = 'none';
element.style.display = 'block';
element.style.display = 'flex';

// INTERDIT — verification fragile
if (element.style.display !== 'none') {
    // ne detecte pas .u-hide
}

Demo interactive

Exception : style.display = ''

La seule utilisation acceptable de .style.display est le nettoyage d'un style inline residuel herite du code legacy : 

// Acceptable — nettoie un style inline legacy
element.style.display = '';

2. Helper toggleDisplay(element, show)

Fonction globale definie dans js/main.js (ligne 37). Raccourci null-safe pour ajouter/retirer .u-hide.

Signature

/**
 * Toggle la visibilite d'un element via la classe CSS .u-hide.
 * @param {HTMLElement|null} element - L'element a montrer/cacher
 * @param {boolean} show - true pour montrer, false pour cacher
 */
window.toggleDisplay = function(element, show) {
    if (!element) return;
    if (show) {
        element.classList.remove('u-hide');
    } else {
        element.classList.add('u-hide');
    }
};
Quand utiliser
  • Affichage conditionnel : toggleDisplay(el, condition)
  • Remplace les ternaires : el.style.display = cond ? 'block' : 'none'
  • Null-safe : pas besoin de verifier if (el) avant l'appel

Exemples

FAIRE
// Conditionnel
toggleDisplay(btnSauver, hasChanges);
toggleDisplay(msgErreur, !isValid);

// Avec querySelector (null-safe)
toggleDisplay(
    document.getElementById('zoneStats'),
    data.length > 0
);
NE PAS FAIRE
// INTERDIT — ternaire inline
el.style.display = cond ? 'flex' : 'none';

// INTERDIT — condition manuelle
if (hasChanges) {
    btnSauver.style.display = 'block';
} else {
    btnSauver.style.display = 'none';
}

3. Pattern modal : .modal-overlay.actif

Les modals utilisent la classe .actif sur le .modal-overlay pour s'afficher. Ce pattern est defini dans styles.css lignes 2774-2789.

CSS (dans styles.css)

.modal-overlay {
    display: none;
    position: fixed;
    top: 0; left: 0;
    width: 100%; height: 100%;
    background: rgba(0, 0, 0, 0.5);
    z-index: 1000;
}

.modal-overlay.actif {
    display: block;
}

Utilisation JS

FAIRE
// Ouvrir un modal
overlay.classList.add('actif');

// Fermer un modal
overlay.classList.remove('actif');
NE PAS FAIRE
// INTERDIT
overlay.style.display = 'block';
overlay.style.display = 'none';

// INTERDIT — ne pas utiliser .u-hide
// pour les .modal-overlay
overlay.classList.remove('u-hide');
Attention
  • .modal-overlay utilise .actif, PAS .u-hide
  • .u-hide est pour les elements normaux, .actif pour les modals
  • Ne jamais mettre style="display:none" sur un .modal-overlay en HTML

4. Boites d'information .info-box

Classes utilitaires pour les messages contextuels. Definies dans styles.css lignes 2462-2484. Remplacent les anciens styles inline style="background: #fff3cd; border-left: 4px solid...".

Variantes

Toutes les variantes
Attention : Ceci est un avertissement. Classe .info-box--attention
Information : Ceci est une info. Classe .info-box--info
Succes : Operation reussie. Classe .info-box--succes
Erreur : Quelque chose a echoue. Classe .info-box--erreur

Code

<!-- Avertissement -->
<div class="info-box info-box--attention">
    <strong>Attention :</strong> Message ici.
</div>

<!-- Information -->
<div class="info-box info-box--info">...</div>

<!-- Succes -->
<div class="info-box info-box--succes">...</div>

<!-- Erreur -->
<div class="info-box info-box--erreur">...</div>
CSS (styles.css)
.info-box {
    padding: 12px 15px;
    border-left: 4px solid;
    border-radius: var(--radius-moyen);
    margin-bottom: 12px;
}
.info-box--attention { background: #fff3cd; border-color: var(--btn-annuler); color: #856404; }
.info-box--info     { background: var(--bleu-tres-pale); border-color: var(--bleu-moyen); }
.info-box--succes   { background: #d4edda; border-color: var(--vert-succes); }
.info-box--erreur   { background: #f8d7da; border-color: var(--rouge-erreur); }

5. Badges source .badge-source

Indicateurs visuels pour l'origine des productions. Definis dans styles.css lignes 2487-2504. Remplacent les anciens style="background: #4caf50; color: white; padding: 2px 6px;".

Variantes

Tous les badges
Locale Bibliotheque Retiree ID-12345

Code

<span class="badge-source badge-source--locale">Locale</span>
<span class="badge-source badge-source--bibliotheque">Bibliotheque</span>
<span class="badge-source badge-source--retiree">Retiree</span>
<span class="badge-source badge-source--id">ID-12345</span>
CSS (styles.css)
.badge-source {
    color: white;
    padding: 2px 6px;
    border-radius: 3px;
    font-size: 0.75em;
    font-weight: 600;
}
.badge-source--locale       { background: var(--vert-succes); }
.badge-source--bibliotheque { background: var(--bleu-clair); }
.badge-source--retiree      { background: var(--orange-accent); }
.badge-source--id           { background: #e0e0e0; color: #666; font-family: monospace; }
Contexte d'utilisation
  • --locale : Production creee directement par l'enseignant
  • --bibliotheque : Production importee depuis une bibliotheque partagee
  • --retiree : Production retiree de la bibliotheque
  • --id : Identifiant technique (debug/admin)
