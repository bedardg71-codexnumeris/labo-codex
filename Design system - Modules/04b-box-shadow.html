Gradients harmonisés • Box-shadow 5 niveaux • Border-radius 12px

1. Gradients harmonisés

Tous les dégradés utilisent la direction 135° (diagonal) avec progression du clair au foncé. L'en-tête et le fond de page sont harmonisés avec les specs des toggles (border-radius 12px).

Gradient en-tête

En-tête avec gradient

linear-gradient(135deg, #032e5c 0%, #0f1e3a 100%)

CSS - En-tête
.entete { background: linear-gradient(135deg, #032e5c 0%, #0f1e3a 100%); border-radius: 0 0 12px 12px; /* Coins arrondis bas seulement */ box-shadow: 0 4px 12px rgba(3, 46, 92, 0.25); padding: 30px; color: white; }
📏 Spécifications en-tête
  • Gradient : 135deg, bleu principal → bleu foncé
  • Border-radius : 0 0 12px 12px (coins arrondis bas uniquement)
  • Box-shadow : 0 4px 12px rgba(3, 46, 92, 0.25) - niveau Prononcé
  • Harmonisé avec : Toggles (même radius 12px)

Gradient fond de page

Le fond de page utilise un gradient bleu très pâle pour créer une atmosphère douce et professionnelle. Les conteneurs blancs (cartes, sidebars) se détachent avec un excellent contraste.

CSS - Fond de page
body { background: linear-gradient(135deg, #e8f2fd 0%, #f0f8ff 100%); min-height: 100vh; } /* Alternative : conteneur principal avec fond */ .page-container { background: linear-gradient(135deg, #e8f2fd 0%, #f0f8ff 100%); min-height: 100vh; }
📏 Spécifications fond page
  • Gradient : 135deg, bleu pâle → bleu très pâle
  • Direction : Toujours 135deg (cohérence totale)
  • Contraste : Conteneurs blancs se détachent parfaitement

2. Système Box-Shadow (5 niveaux)

Palette d'ombres harmonisée pour créer de la profondeur visuelle. Tous les box-shadow utilisent la couleur bleu principal (rgba(3, 46, 92, ...)) pour cohérence.

Les 5 niveaux d'ombre

Subtil
0 1px 4px
rgba(3, 46, 92, 0.1)
Normal
0 2px 8px
rgba(3, 46, 92, 0.15)
Prononcé
0 4px 12px
rgba(3, 46, 92, 0.25)
Fort
0 8px 24px
rgba(3, 46, 92, 0.3)
Inset
inset 0 1px 3px
rgba(3, 46, 92, 0.08)
CSS - Palette Box-Shadow
/* Niveau 1 : Subtil (sections, items) */ .shadow-subtil { box-shadow: 0 1px 4px rgba(3, 46, 92, 0.1); } /* Niveau 2 : Normal (cartes, sidebars, conteneurs) */ .shadow-normal { box-shadow: 0 2px 8px rgba(3, 46, 92, 0.15); } /* Niveau 3 : Prononcé (en-tête, hover sur cartes) */ .shadow-prononce { box-shadow: 0 4px 12px rgba(3, 46, 92, 0.25); } /* Niveau 4 : Fort (modaux, éléments flottants) */ .shadow-fort { box-shadow: 0 8px 24px rgba(3, 46, 92, 0.3); } /* Niveau 5 : Inset (panneaux, toggles, inputs) */ .shadow-inset { box-shadow: inset 0 1px 3px rgba(3, 46, 92, 0.08); }
📐 Usage recommandé
  • Subtil : Sections collapsibles, items de liste
  • Normal : Cartes, sidebars, bibliothèques
  • Prononcé : En-tête, hover sur cartes
  • Fort : Modaux, dropdowns, éléments flottants
  • Inset : Panneaux de saisie, toggles, inputs

3. Border-Radius harmonisé (12px)

Pour harmoniser avec les toggles, le border-radius principal passe à 12px pour tous les conteneurs. Les petits éléments restent à 6px.

Système 2 niveaux de border-radius

CSS - Border-Radius
/* NIVEAU 1 : Border-radius 12px (conteneurs) */ .entete, .carte, .sidebar, .modal-content, .section-collapsible, .panneau-saisie, .carte-bibliotheque, input[type="checkbox"] { /* toggles */ border-radius: 12px; } /* En-tête : coins arrondis bas seulement */ .entete { border-radius: 0 0 12px 12px; } /* NIVEAU 2 : Border-radius 6px (petits éléments) */ .btn, .input-text, .select, .textarea { border-radius: 6px; } /* NIVEAU 3 : Border-radius 20px (pills uniformes) */ .badge-pratique, .badge-criteres { border-radius: 20px; } /* NIVEAU 4 : Border-radius 5px (badges Tétris) */ .badge-absence, .badge-intervention { border-radius: 5px; }
📏 Progression border-radius
  • 5px : Badges Tétris (compact)
  • 6px : Boutons, inputs (petits éléments)
  • 12px : Conteneurs (harmonisé toggles) ⭐
  • 20px : Pills (badges pratique, matériel péda)
  • Logique : 5px → 6px → 12px (+ 20px pills)

Carte exemple

5. Variables CSS recommandées

Variables complètes

CSS - Variables :root
:root { /* === GRADIENTS === */ --gradient-entete: linear-gradient(135deg, #032e5c 0%, #0f1e3a 100%); --gradient-fond-page: linear-gradient(135deg, #e8f2fd 0%, #f0f8ff 100%); /* === BOX-SHADOW (5 niveaux) === */ --shadow-subtil: 0 1px 4px rgba(3, 46, 92, 0.1); --shadow-normal: 0 2px 8px rgba(3, 46, 92, 0.15); --shadow-prononce: 0 4px 12px rgba(3, 46, 92, 0.25); --shadow-fort: 0 8px 24px rgba(3, 46, 92, 0.3); --shadow-inset: inset 0 1px 3px rgba(3, 46, 92, 0.08); /* === BORDER-RADIUS === */ --radius-petit: 5px; /* Badges Tétris */ --radius-moyen: 6px; /* Boutons, inputs */ --radius-grand: 12px; /* Conteneurs (harmonisé toggles) */ --radius-pill: 20px; /* Pills uniformes */ }
Utilisation des variables
.entete { background: var(--gradient-entete); border-radius: 0 0 var(--radius-grand) var(--radius-grand); box-shadow: var(--shadow-prononce); } .carte { border-radius: var(--radius-grand); box-shadow: var(--shadow-normal); } .carte:hover { box-shadow: var(--shadow-prononce); }
