Modals

Les modals (fenêtres modales) sont des composants overlay qui apparaissent au-dessus du contenu principal pour afficher des informations importantes, des formulaires ou demander une confirmation à l'utilisateur. Ils bloquent l'interaction avec le reste de l'interface jusqu'à ce qu'ils soient fermés.

Structure HTML de base

Tous les modals suivent une structure en deux couches : l'overlay (fond semi-transparent) et le contenu du modal (carte blanche au centre).

HTML Pattern
<!-- Modal avec overlay --> <div id="monModal" class="modal-overlay"> <div class="modal-contenu"> <!-- En-tête avec titre et bouton fermer --> <div class="modal-entete"> <h2>Titre du modal</h2> <button class="btn-fermer" onclick="fermerModal()">×</button> </div> <!-- Corps du modal --> <div class="modal-corps"> <!-- Contenu ici --> </div> <!-- Pied avec actions --> <div class="modal-pied"> <button class="btn btn-annuler" onclick="fermerModal()">Annuler</button> <button class="btn btn-principal" onclick="sauvegarder()">Sauvegarder</button> </div> </div> </div>
📋 Structure hiérarchique
  • .modal-overlay : Conteneur principal avec fond semi-transparent (position: fixed)
  • .modal-contenu : Carte blanche centrée contenant le modal
  • .modal-entete : Titre + bouton de fermeture
  • .modal-corps : Contenu principal (scrollable si nécessaire)
  • .modal-pied : Actions (boutons Annuler/Confirmer)

Classes CSS et styles

Styles standardisés pour tous les modals de l'application.

/* Overlay - Fond semi-transparent */ .modal-overlay { position: fixed; top: 0; left: 0; width: 100%; height: 100%; background: rgba(3, 46, 92, 0.5); display: flex; align-items: center; justify-content: center; z-index: 1000; backdrop-filter: blur(2px); } /* Contenu du modal - Carte blanche centrée */ .modal-contenu { background: white; border-radius: 12px; box-shadow: 0 8px 32px rgba(0, 0, 0, 0.3); max-width: 600px; width: 90%; max-height: 85vh; display: flex; flex-direction: column; overflow: hidden; } /* En-tête */ .modal-entete { padding: 24px 30px; border-bottom: 2px solid #e8f2fd; display: flex; justify-content: space-between; align-items: center; } .modal-entete h2 { margin: 0; color: #032e5c; font-size: 1.5rem; } /* Corps - scrollable */ .modal-corps { padding: 30px; overflow-y: auto; flex: 1; } /* Pied avec actions */ .modal-pied { padding: 20px 30px; border-top: 1px solid #e8f2fd; display: flex; justify-content: flex-end; gap: 12px; } /* Bouton fermer (×) */ .btn-fermer { background: none; border: none; font-size: 2rem; color: #666; cursor: pointer; padding: 0; width: 32px; height: 32px; display: flex; align-items: center; justify-content: center; border-radius: 6px; transition: all 0.2s ease; } .btn-fermer:hover { background: #f0f8ff; color: #032e5c; }

Variantes de taille

Trois tailles standard pour s'adapter au contenu : petit, moyen (défaut), grand.

📏 Dimensions
  • Petit (.modal-petit) : max-width: 400px - Confirmations simples
  • Moyen (défaut) : max-width: 600px - Formulaires standards
  • Grand (.modal-grand) : max-width: 800px - Bibliothèques, contenu riche
  • Très grand (.modal-tres-grand) : max-width: 1000px - Tableaux, aperçus
CSS - Variantes
/* Petit modal */ .modal-contenu.modal-petit { max-width: 400px; } /* Grand modal */ .modal-contenu.modal-grand { max-width: 800px; } /* Très grand modal */ .modal-contenu.modal-tres-grand { max-width: 1000px; }
Exemple d'utilisation
<!-- Modal de bibliothèque (grand) --> <div id="modalBibliotheque" class="modal-overlay"> <div class="modal-contenu modal-grand"> <!-- Contenu --> </div> </div>

Animations et transitions

Animations fluides pour l'apparition et la disparition des modals.

CSS - Animations
/* Animation d'apparition */ @keyframes fadeIn { from { opacity: 0; } to { opacity: 1; } } @keyframes slideIn { from { opacity: 0; transform: translateY(-30px) scale(0.95); } to { opacity: 1; transform: translateY(0) scale(1); } } /* Application des animations */ .modal-overlay { animation: fadeIn 0.3s ease; } .modal-contenu { animation: slideIn 0.3s ease; }

Gestion JavaScript

Fonctions standard pour ouvrir, fermer et gérer les modals.

JavaScript - Pattern de base
// Créer et afficher un modal function afficherModal(id, contenu) { // Créer le HTML du modal const modalHTML = ` <div id="${id}" class="modal-overlay"> <div class="modal-contenu"> <div class="modal-entete"> <h2>Titre</h2> <button class="btn-fermer" onclick="fermerModal('${id}')">×</button> </div> <div class="modal-corps"> ${contenu} </div> <div class="modal-pied"> <button class="btn btn-annuler" onclick="fermerModal('${id}')">Fermer</button> </div> </div> </div> `; // Injecter dans le DOM document.body.insertAdjacentHTML('beforeend', modalHTML); // Fermer au clic sur l'overlay document.getElementById(id).addEventListener('click', (e) => { if (e.target.classList.contains('modal-overlay')) { fermerModal(id); } }); } // Fermer et supprimer un modal function fermerModal(id) { const modal = document.getElementById(id); if (modal) { modal.remove(); } } // Fermer à la touche Escape document.addEventListener('keydown', (e) => { if (e.key === 'Escape') { const modals = document.querySelectorAll('.modal-overlay'); if (modals.length > 0) { modals[modals.length - 1].remove(); } } });

Pattern spécifique : Bibliothèques

Les modals de bibliothèque (Productions, Grilles, Échelles, etc.) suivent un pattern standardisé avec deux sections : « Ma bibliothèque » et « Bibliothèque partagée ».

📋 Anatomie d'une bibliothèque
  • Modal grand : max-width: 800px pour afficher les cartes confortablement
  • Deux sections : Ma bibliothèque (éditable) + Bibliothèque partagée (lecture seule)
  • Cartes cliquables : Sélection visuelle avec bordure bleue épaissie
  • Actions contextuelles : Modifier/Supprimer (ma biblio), Dupliquer (partagée)
  • Bouton « Partager » : Ouvre sous-modal pour métadonnées CC BY-NC-SA 4.0
Flux d'interaction
  1. Clic sur « Consulter la bibliothèque » dans la sidebar → Ouvre modal
  2. Sélection d'une carte → Bordure bleue + boutons d'action visibles
  3. Clic « Modifier » → Ouvre formulaire d'édition
  4. Sauvegarde → Rafraîchit le modal ET la sidebar
  5. Clic « Partager » → Ouvre sous-modal pour métadonnées
JavaScript - Rafraîchissement
// Après toute modification, rafraîchir MODAL + SIDEBAR function apresModification() { // 1. Rafraîchir le modal rafraichirModalBibliotheque(); // 2. Rafraîchir la sidebar rafraichirSidebar(); }

⚠️ Accessibilité et focus

Bonnes pratiques pour garantir l'accessibilité des modals.

📋 Checklist accessibilité
  • Focus piège : Le focus doit rester dans le modal (tab ne sort pas)
  • Fermeture Escape : La touche Escape ferme toujours le modal
  • Clic overlay : Cliquer en dehors du modal le ferme
  • ARIA labels : role="dialog", aria-labelledby, aria-modal="true"
  • Focus initial : Placer le focus sur le premier élément interactif
  • Retour du focus : À la fermeture, redonner le focus à l'élément déclencheur
HTML - ARIA complet
<div id="monModal" class="modal-overlay" role="dialog" aria-modal="true" aria-labelledby="titre-modal"> <div class="modal-contenu"> <div class="modal-entete"> <h2 id="titre-modal">Titre du modal</h2> <button class="btn-fermer" onclick="fermerModal()" aria-label="Fermer le modal">×</button> </div> <!-- Reste du modal --> </div> </div>

Usage des emojis dans les modals

Règle critique : L'emoji ⚠️ (triangle avertissement) est autorisé UNIQUEMENT dans les modals pour les messages d'alerte critiques. Il ne doit JAMAIS apparaître dans les messages inline.

✅ CORRECT
<!-- Modal de confirmation --> <div class="modal-corps"> <p style="text-align: center;"> ⚠️ <strong>Attention</strong> </p> <p>Cette action est irréversible.</p> </div>
❌ INCORRECT
<!-- Message inline (INTERDIT) --> <div class="alerte alerte-attention"> ⚠️ Certaines évaluations... </div>

Bonnes pratiques

✅ À FAIRE
  • Supprimer le modal du DOM avec .remove() à la fermeture
  • Rafraîchir le modal ET la sidebar après modification
  • Utiliser max-width adapté au contenu
  • Ajouter backdrop-filter: blur(2px) sur l'overlay
  • Fermer à l'Escape et au clic sur overlay
  • Placer le focus sur le premier champ au chargement
  • Limiter la hauteur (max-height: 85vh) et rendre scrollable
❌ À ÉVITER
  • Oublier de rafraîchir le modal après une action
  • Laisser le modal en display: none (toujours supprimer du DOM)
  • Empiler plusieurs modals (fermer le précédent)
  • Utiliser ⚠️ en dehors des modals
  • Bloquer le scroll du body sans le réactiver
  • Oublier les attributs ARIA pour l'accessibilité
  • Modal trop haut (doit rester visible sans scroll vertical du viewport)
