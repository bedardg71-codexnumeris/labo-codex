Panneau chantier (toast de mise à jour)

Notification fixe en haut à droite, inspirée des panneaux de signalisation routière québécois. Utilisée pour signaler une mise à jour déployée en arrière-plan. Le style évoque un chantier routier : fond orange construction, texte noir, contour intérieur décalé du bord comme sur un vrai panneau, et coins arrondis.

Spécifications du panneau chantier
  • Fond : #E8700A (orange construction, uni, sans dégradé)
  • Texte : #1a1a1a (noir quasi-pur)
  • Contour intérieur : 2.5px solid #1a1a1a, décalé de 6px du bord (via ::before absolu)
  • Coins extérieurs : border-radius: 14px
  • Coins du contour : border-radius: 9px
  • Largeur max : 340px
  • Padding : 22px 24px
  • Ombre : 0 6px 24px rgba(0, 0, 0, 0.35)
  • Position : fixed, top: 20px, right: 20px, z-index: 10000
  • Animation : slide-in depuis la droite (translateX + opacity, 0.4s ease)
Structure du contenu
  • Bouton fermer (×) : position absolute, top: 6px, right: 10px, opacity 0.7 → 1 au hover
  • En-tête : flèche ➡︎ (1.4rem) + numéro de build en majuscules (font-weight: 900)
  • Message : texte descriptif en minuscules (0.78rem, font-weight: 600)
  • Footer : date à gauche (0.72rem, opacité 65%) + bouton à droite (justify-content: space-between)
  • Bouton Recharger : fond #1a1a1a, texte #E8700A, uppercase, font-weight: 800, border-radius: 6px

À FAIRE
  • Utiliser ce panneau uniquement pour les mises à jour système
  • Toujours offrir un bouton de fermeture (×)
  • Garder le contour intérieur décalé (signature panneau routier)
  • Conserver le fond orange #E8700A uni (pas de dégradé)
  • Date et bouton dans le footer, séparés gauche/droite
À ÉVITER
  • Ajouter un dégradé ou du blanc sur le fond orange
  • Utiliser du texte blanc (toujours noir #1a1a1a)
  • Dépasser 340px de largeur
  • Utiliser ce style pour d'autres types de notifications
  • Omettre l'animation slide-in depuis la droite
