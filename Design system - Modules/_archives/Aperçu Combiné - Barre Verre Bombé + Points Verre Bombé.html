Effet tourbillon - Comment ça marche
Animation float-vertical :
• Mouvement vertical (haut ↔ bas) selon --amp (8-18px)
• Changement d'échelle : --scaleUp (devant) → --scaleDown (derrière)
• Durée variable : --duration (4-8s) - plus court = plus rapide
• animation-delay différent = déphasage entre points

Effet tourbillon :
• Points groupés à la même position horizontale (±2%)
• Chaque point a des paramètres différents (amp, duration, delay)
• Les points se "croisent" visuellement → illusion de rotation 3D
• z-index dynamique (--zUp / --zDown) renforce la profondeur
