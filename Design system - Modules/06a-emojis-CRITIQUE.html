Toggle avec carte de conseil pratique

Toggle cliquable avec emoji sur la ligne de titre, affichant une carte style post-it jaune pour les conseils pratiques.

💡
💡 Conseil pratique :
  • Cours actif : Un seul cours peut être actif Ã  la fois. Le cours actif est utilisé comme référence dans toute l'application
  • Verrouillage : Verrouillez un cours terminé pour éviter les modifications accidentelles
  • Duplication : Dupliquez un cours pour créer rapidement une nouvelle session en modifiant seulement l'année
  • Code de cours : Format habituel : XXX-XXX-XX (département-numéro-pondération)
  • Format horaire : Définit comment les heures sont réparties dans la semaine (utilisé pour le calendrier)

  • Bordure gauche: 4px solide jaune (#f5c842), droite (pas de coins arrondis Ã  gauche)
  • Coins: Arrondis uniquement Ã  droite (6px)
  • Animation: Slide-down smooth (0.3s ease)
