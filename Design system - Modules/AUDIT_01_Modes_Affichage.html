🔴 AUDIT 01 : Modes d'affichage

Renommer « Simulation » → « Assisté »

Priorité : CRITIQUE Durée : 45 minutes Fichiers : ~10
← Retour aux fiches d'audit

🎯 Objectif

Renommer toutes les références à « Simulation » par « Assisté » pour refléter la nouvelle terminologie du mode d'affichage avec données de démonstration.

📋 Contexte

L'application possède 3 modes d'affichage :

Les 3 modes
  1. Mode Normal : Données réelles (palette bleue)
  2. Mode Assisté : Données de démonstration (palette sarcelle) - ANCIENNEMENT « Simulation »
  3. Mode Anonymisation : Protection des données (bleus désaturés)

Le mode « Simulation » a été renommé « Assisté » mais de nombreuses références obsolètes subsistent dans le code.

🔍 Patterns de recherche

Pattern 1 : Attributs HTML
Chercher: data-mode="simulation" Remplacer: data-mode="assisté" Chercher: \[data-mode="simulation"\] Remplacer: [data-mode="assisté"]
Pattern 2 : Texte visible
Chercher: Mode Simulation Remplacer: Mode Assisté Chercher: mode Simulation Remplacer: mode Assisté Chercher: mode simulation Remplacer: mode assisté
Pattern 3 : Variables JavaScript
Chercher: modeSimulation Remplacer: modeAssisté Chercher: 'simulation' Remplacer: 'assisté' Chercher: "simulation" Remplacer: "assisté"

✅ Exemples de corrections

Exemple 1 : CSS

❌ AVANT
[data-mode="simulation"] { --bleu-principal: var(--sarcelle-principal); } /* Mode Simulation - Sarcelle/vert */ body[data-mode="simulation"] .entete { background: linear-gradient(135deg, #1a5266 0%, #0d3540 100%); }
✅ APRÈS
[data-mode="assisté"] { --bleu-principal: var(--sarcelle-principal); } /* Mode Assisté - Sarcelle/vert */ body[data-mode="assisté"] .entete { background: linear-gradient(135deg, #1a5266 0%, #0d3540 100%); }

Exemple 2 : JavaScript

❌ AVANT
const modeApplication = localStorage.getItem('modeApplication') || 'simulation'; if (modeApplication === 'simulation') { chargerDonneesDemo(); } const labelMode = 'Mode Simulation';
✅ APRÈS
const modeApplication = localStorage.getItem('modeApplication') || 'assisté'; if (modeApplication === 'assisté') { chargerDonneesDemo(); } const labelMode = 'Mode Assisté';

Exemple 3 : HTML

❌ AVANT
<body data-mode="simulation"> <button onclick="activerModeSimulation()"> Mode Simulation </button> </body>
✅ APRÈS
<body data-mode="assisté"> <button onclick="activerModeAssisté()"> Mode Assisté </button> </body>

⚠️ Points d'attention

Migration localStorage

Si des données sont stockées avec la clé 'simulation', prévoir une migration automatique :

// Migration automatique if (localStorage.getItem('modeApplication') === 'simulation') { localStorage.setItem('modeApplication', 'assisté'); }
Noms de fonctions

Renommer systématiquement :

  • activerModeSimulation() → activerModeAssisté()
  • estModeSimulation() → estModeAssisté()
  • basculerVersSimulation() → basculerVersAssisté()
Commentaires de code

Ne pas oublier les commentaires :

// ❌ AVANT : Initialisation mode simulation // ✅ APRÈS : Initialisation mode assisté
