🎯 Style Tétris : Badges compacts et cohérents

Tous les badges de l'application utilisent désormais le **style Tétris** : dimensions uniformes, design compact et empilable. Ce système garantit une cohérence visuelle totale et économise environ 15% d'espace écran.

✅ Spécifications Tétris (appliquées partout)

Badges principaux :
  • Padding : 3px 8px
  • Font-size : 0.75rem (12px)
  • Border-radius : 5px
  • Gap : 5px
Badges internes (heures, notes) :
  • Padding : 2px 6px
  • Font-size : 0.7rem (11.2px)
  • Border-radius : 3px

Résultat : Hauteur uniforme ~24px • Style empilable • Lisibilité préservée • +15% d'espace économisé

Variables CSS - Style Tétris
:root { /* Badges principaux */ --badge-padding: 3px 8px; --badge-font-size: 0.75rem; --badge-border-radius: 5px; --badge-gap: 5px; /* Badges internes */ --badge-compact-padding: 2px 6px; --badge-compact-font-size: 0.7rem; --badge-compact-border-radius: 3px; /* Commun */ --badge-font-weight: 600; --badge-line-height: 1.2; --badge-transition: all 0.2s ease; }

Bonnes pratiques - Style Tétris

✅ À FAIRE
  • Utiliser les specs Tétris partout
  • Padding 3px 8px pour tous les badges principaux
  • Padding 2px 6px pour tous les badges internes
  • Font 0.75rem / 0.7rem systématiquement
  • Border-radius 5px / 3px (sauf pills)
  • Gap de 10px entre badges pour effet Tétris
  • HTML entities pour emojis (👥, etc.)
❌ À ÉVITER
  • Dimensions personnalisées (casse la cohérence)
  • Font-size > 0.75rem (trop gros)
  • Font-size < 0.7rem (illisible)
  • Border-radius variable (4px, 8px, 12px...)
  • Padding 4px 6px ou 4px 10px (ancien style)
  • Emojis UTF-8 natifs (problèmes encodage)
  • Gap < 10px (badges trop serrés)

🎯 Résumé : Règle unique à retenir

/* Tous les badges principaux */ padding: 3px 8px; font-size: 0.75rem; border-radius: 5px; gap: 5px; font-weight: 600; line-height: 1.2; /* Tous les badges internes */ padding: 2px 6px; font-size: 0.7rem; border-radius: 3px; /* Exception : pills (SOM/PAN) */ border-radius: 20px; padding: 3px 10px;
