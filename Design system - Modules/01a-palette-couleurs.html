1.5 Principes de design uniformes

Règles et standards appliqués de manière cohérente dans toute l'interface pour assurer une expérience utilisateur fluide et prévisible. Ces principes s'appliquent aux trois modes.

Direction des dégradés (Standard 135Â°)
📐 Règle absolue de direction
  • Tous les dégradés: 135Â° diagonal (du coin supérieur gauche au coin inférieur droit)
  • Ordre des couleurs: TOUJOURS de la couleur claire vers la couleur foncée
  • Format standard: linear-gradient(135deg, couleur-claire 0%, couleur-foncée 100%)
  • Exemples conformes:
    • linear-gradient(135deg, var(--bleu-moyen) 0%, var(--bleu-principal) 100%)
    • linear-gradient(135deg, var(--bleu-tres-pale) 0%, var(--bleu-pale) 100%)
    • linear-gradient(135deg, #2a4a8a 0%, #032e5c 100%)
  • Cohérence: Pas d'exceptions - tous les dégradés suivent cette règle

États des composants (Normal / Hover / Active)
🎨 Hiérarchie visuelle par état
  • État Normal: Couleur solide avec variables CSS (var(--bleu-pale), var(--bleu-principal), etc.)
  • État Hover: Dégradé + transformation légère (translateY, scale)
  • État Active: Couleur plus CLAIRE (plus pâle) avec bordure épaissie
  • Principe: L'activation éclaircit plutôt que d'assombrir (cohérence avec boutons)
  • Transitions: Toutes les transitions en 0.3s ease (fluidité)
Code CSS - Pattern d'états (Badges et cartes)
/* BADGES - Pattern standard (styles.css lignes 5069-5088) */ .badge-grille, .sidebar-item-badge { /* État Normal: Couleur solide */ background: var(--bleu-principal); color: white; padding: 3px 10px; border-radius: 12px; transition: background 0.3s ease, transform 0.2s ease; } .badge-grille:hover, .sidebar-item-badge:hover { /* État Hover: Dégradé + élévation */ background: linear-gradient(135deg, var(--bleu-moyen) 0%, var(--bleu-principal) 100%); transform: translateY(-1px); box-shadow: 0 2px 6px rgba(3, 46, 92, 0.4); } /* CARTES - Pattern standard (styles.css lignes 5038-5092) */ .sidebar-item { /* État Normal: Couleur solide pâle */ padding: 12px; background: var(--bleu-pale); border-radius: 6px; border: 1px solid var(--bleu-leger); transition: all 0.3s ease; } .sidebar-item:hover { /* État Hover: Dégradé + élévation */ background: linear-gradient(135deg, var(--bleu-tres-pale) 0%, var(--bleu-pale) 100%); border-color: var(--bleu-moyen); box-shadow: 0 2px 6px rgba(3, 46, 92, 0.15); transform: translateY(-1px); } .sidebar-item.active { /* État Active: Plus CLAIR (pas plus foncé) */ border: 2px solid var(--bleu-principal); background: var(--bleu-tres-pale); /* Lighter, not darker! */ box-shadow: 0 3px 10px rgba(3, 46, 92, 0.25); }

Fond de page et hiérarchie visuelle

Pour créer une hiérarchie visuelle claire, le fond de page utilise une couleur saturée adaptée au mode actif, tandis que les sections de contenu restent blanches avec des ombres renforcées. Cela permet aux cartes et sections de ressortir clairement du fond.

Le fond de page s'adapte automatiquement au mode sélectionné pour maintenir la cohérence visuelle tout en offrant un contraste optimal avec les sections blanches.

Ombres portées renforcées

Les sections et cartes blanches utilisent des ombres portées renforcées (double couche) pour créer un effet de profondeur et mieux se détacher du fond coloré.

📋 Principe des ombres doubles
  • Première couche : Ombre proche et légère (0 2px 4px, opacité 0.08)
  • Deuxième couche : Ombre éloignée et diffuse (0 4px 12px, opacité 0.15)
  • Couleur : Adaptée au mode (bleu, sarcelle ou gris-vert)
  • Effet : Élévation et profondeur naturelle
CSS - Ombres par mode
/* Sections blanches - Mode Normal (bleu) */ [data-mode="normal"] .section, [data-mode="normal"] .carte { background: white; border-radius: 8px; box-shadow: 0 2px 4px rgba(3, 46, 92, 0.08), 0 4px 12px rgba(3, 46, 92, 0.15); border: 1px solid rgba(3, 46, 92, 0.04); } /* Sections blanches - Mode Assisté (sarcelle) */ [data-mode="assisté"] .section, [data-mode="assisté"] .carte { background: white; border-radius: 8px; box-shadow: 0 2px 4px rgba(30, 90, 74, 0.08), 0 4px 12px rgba(30, 90, 74, 0.15); border: 1px solid rgba(30, 90, 74, 0.04); } /* Sections blanches - Mode Anonymisation (gris-vert) */ [data-mode="anonymisation"] .section, [data-mode="anonymisation"] .carte { background: white; border-radius: 8px; box-shadow: 0 2px 4px rgba(90, 122, 122, 0.08), 0 4px 12px rgba(90, 122, 122, 0.15); border: 1px solid rgba(90, 122, 122, 0.04); }

  • Utiliser le fond adapté au mode actif

  • Sections colorées au lieu de blanches
