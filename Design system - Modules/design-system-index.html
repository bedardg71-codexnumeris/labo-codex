🎨 Design System Monitorage v7

Palette Nuit Élégante • Guide de référence complet • 1er janvier 2026

📖 À propos de ce guide

Ce Design System documente l'ensemble des composants, styles et patterns utilisés dans l'application de monitorage pédagogique. Il garantit la cohérence visuelle et facilite le développement en fournissant des exemples concrets et des spécifications précises.

Organisation modulaire :

  • Fondations : Palette de couleurs (modes Normal/Assisté/Anonymisation), typographie
  • Composants de base : Boutons, formulaires, badges
  • Composants de données : Tableaux, cartes, barres de gradient
  • Composants de layout : Navigation, sidebars, en-tête
  • Patterns pédagogiques : Matériel pédagogique, bibliothèques
  • Composants interactifs : Toggles d'information, messages et alertes
  • Primo Assistant : Modal d'accueil, parcours guidés, mode assisté

Règles critiques :

  • Emojis autorisés uniquement : 😎 (Primo), 💡📋🎓 (toggles), ⚠️ (alertes), ✉️ (contact)
  • Modes d'affichage : Normal (bleu), Assisté (sarcelle), Anonymisation (gris-vert)
  • Aucun émoji décoratif ailleurs dans l'application

Module 1 : Fondations

1a. Palette de couleurs

Couleurs des trois modes d'affichage (Normal, Assisté, Anonymisation), variables CSS, codes hexadécimaux, couleurs des boutons et principes de design uniformes.

1b. Typographie

Hiérarchie des titres (H1-H4), tailles de police, spécifications et conventions typographiques.

Module 2 : Composants de base

2a. Boutons

Types de boutons par fonction (principal, ajouter, modifier, annuler, supprimer), tailles (large, standard, compact) et règles automatiques de dimensionnement.

2b. Formulaires

Champs de texte, zones de texte, sélecteurs, cases à cocher, boutons radio et composants de saisie avec états et validation.

2c. Badges Tétris

Badges de statut, indicateurs visuels, pastilles de notification et étiquettes avec codes couleur sémantiques.

Module 3 : Composants de données

3a. Tableaux

Tableaux de données avec styles, interactions et états de rangées (hover, sélection, tri).

3b. Cartes et sidebars

Cartes d'information, sidebars de navigation latérale, layouts et zones de contenu structuré.

3c. Barres de gradient

Barres visuelles pour indices A-C-P-E, patterns d'apprentissage et RàI avec points de distribution.

3d. Modals NOUVEAU

Fenêtres modales : structure, variantes de taille, accessibilité, exemples (bibliothèques, confirmations, Primo).

Module 4 : Composants de layout

4a. Navigation

Navigation principale et secondaire avec boutons glassmorphism et adaptation aux modes.

4b. Box-shadow et En-têtes

Niveaux de box-shadow, en-tête avec gradient "Nuit Élégante" et zones de conteneurs.

Module 5 : Patterns pédagogiques

Matériel pédagogique

Layout sidebar + zone principale pour productions, grilles, échelles, cartouches et objectifs.

Bibliothèques

Modals de gestion avec sections "Ma sélection" et "Disponibles à ajouter", import/export Creative Commons.

Module 6 : Composants interactifs

6a. Emojis (CRITIQUE)

Liste restrictive des emojis autorisés et contextes d'usage (toggles, alertes uniquement).

6b. Toggles d'information

Cartes pliables avec emojis (conseils pratiques), (spécifications), (pédagogie).

6c. Messages et alertes

Messages d'information, succès, avertissement, erreur avec emoji pour alertes modales.

Module 7 : Primo Assistant 😎

Modal d'accueil Primo

Modal d'accueil conversationnel pour nouveaux utilisateurs avec emoji 😎 et 4 parcours guidés.

Parcours guidés

Module 1 (Créer un groupe), Module 2 (Évaluer), Module 3 (Diagnostics), Module 4 (Wizard de pratique).

Mode Assisté

Palette sarcelle/vert, données de démonstration, interface adaptée pour l'apprentissage.
