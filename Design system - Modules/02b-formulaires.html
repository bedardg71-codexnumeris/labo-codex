Boutons X de fermeture et réinitialisation

Deux types de boutons X sont utilisés dans l'interface, avec des couleurs différentes selon leur fonction : orange pour la réinitialisation (action réversible) et rouge pour l'annulation/fermeture (action immédiate).

Panneau
X Orange
Réinitialisation (avec confirmation)
Formulaire
X Rouge
Annulation/Fermeture (immédiat)
🎨 Spécifications des boutons X
  • Position: absolute, top: 8px, right: 8px
  • Style: background: none, border: none, font-size: 1.2rem
  • Cursor: pointer
  • X Orange (réinitialisation): color: var(--orange-accent) #ff6b35 - Utilisé pour réinitialiser des données (avec confirmation)
  • X Rouge (annulation): color: var(--rouge-danger) #dc3545 - Utilisé pour fermer un formulaire ou annuler une action
Code CSS inline
/* X Orange - Réinitialisation */ style="position: absolute; top: 8px; right: 8px; background: none; border: none; font-size: 1.2rem; cursor: pointer; color: var(--orange-accent); padding: 0; line-height: 1;" /* X Rouge - Annulation/Fermeture */ style="position: absolute; top: 8px; right: 8px; background: none; border: none; font-size: 1.2rem; cursor: pointer; color: var(--rouge-danger); padding: 0; line-height: 1;"
⚠️ Bonnes pratiques
  • Le X orange doit toujours déclencher une confirmation avant l'action (ex: "Voulez-vous vraiment réinitialiser...")
  • Le X rouge ferme/annule immédiatement sans confirmation
  • Le X doit avoir un attribut title descriptif (ex: "Réinitialiser", "Annuler", "Fermer")
  • Le conteneur parent doit avoir position: relative pour le positionnement absolu
