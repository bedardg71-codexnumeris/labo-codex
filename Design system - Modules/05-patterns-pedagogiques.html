5bis. Pattern Matériel pédagogique avec bibliothèque

Pattern réutilisable pour gérer du matériel pédagogique partageable (Productions, Grilles, Échelles, Cartouches, Pratiques). Comprend une sidebar de navigation, une zone d'édition, un système de bibliothèque avec partage Creative Commons.

ðŸ“¦ Vue d'ensemble du pattern

Ce pattern est utilisé pour tous les types de matériel pédagogique qui peuvent être : (1) créés par l'enseignant, (2) partagés avec la communauté (export/import), (3) retirés temporairement de la vue.

ðŸ”‘ Propriété clé : dansBibliotheque
  • true ou undefined: Item visible dans la sidebar
  • false: Item retiré (disponible Ã  réajouter depuis bibliothèque)
  • Utilité: Soft-delete permettant de cacher temporairement sans supprimer
  • Workflow: Créer (true) â†’ Retirer (false) â†’ Réajouter (true)
ðŸ“¤ Partage avec Creative Commons
  • Bouton "Partager": Ouvre modal pour collecter métadonnées CC BY-NC-SA 4.0
  • Métadonnées collectées: Auteur, institution, discipline, description, niveau
  • Export JSON: Inclut données + métadonnées + licence CC
  • Import JSON: Détection format (ancien vs nouveau), remapping IDs, validation
  • Module cc-license.js: Gère toute la logique Creative Commons

âš¡ Workflow JavaScript
  1. Ouverture modal : afficherBibliotheque[Type]()
    • Récupère tous les éléments utilisateur
    • Filtre en 2 groupes : dansBibliotheque !== false vs = false
    • Récupère bibliothèque partagée (window.[TYPE]_BIBLIOTHEQUE)
    • Génère HTML complet avec compteurs dynamiques
    • Insère dans DOM avec insertAdjacentHTML('beforeend')
  2. Partager : partager[Type](id)
    • Appelle demanderMetadonneesEnrichies()
    • Ajoute metadata_cc Ã  l'objet
    • Change dansBibliotheque = false (retire de sélection)
    • Sauvegarde et rafraîchit modal + sidebar
  3. Retirer : retirer[Type]DeBibliotheque(id)
    • Change dansBibliotheque = false
    • Sauvegarde et rafraîchit modal + sidebar
  4. Ajouter : ajouter[Type]Individuelle(id)
    • Change dansBibliotheque = true
    • Sauvegarde et rafraîchit modal + sidebar
  5. Fermer : fermerModalBibliotheque[Type]()
    • Supprime le modal du DOM avec .remove()
âœ… À FAIRE
  • Utiliser le flag dansBibliotheque pour gérer la visibilité
  • Collecter les métadonnées CC avant partage (sauf données ministérielles)
  • Générer de nouveaux IDs lors de l'import pour éviter conflits
  • Afficher un message "Sélectionnez..." quand aucun item actif
  • Utiliser les classes .sidebar-item, .sidebar-item-titre, .sidebar-item-badge
  • Grouper les items par discipline dans Section 2
  • Afficher badge "Retirée" pour items précédemment sélectionnés
  • Rafraîchir modal ET sidebar après chaque action
âŒ À ÉVITER
  • Supprimer définitivement les items (utiliser dansBibliotheque = false)
  • Oublier les métadonnées CC pour créations personnelles
  • Réutiliser les IDs lors de l'import (risque de collision)
  • Laisser le formulaire visible par défaut (UX déroutante)
  • Créer des styles custom inline au lieu d'utiliser les classes
  • Oublier de rafraîchir le modal après modification
  • Mélanger les éléments retirés avec ceux jamais utilisés
⚠️ Exception : Données ministérielles

Pour les configurations de cours (données ministérielles publiques), le workflow est simplifié sans Creative Commons : pas de bouton "Partager", pas de collecte de métadonnées, export/import JSON direct. Les cours ne sont pas des créations personnelles.
