Bouton actif par section (Lot J phase 2 — 26 mai 2026)

Quand l'utilisateur est sur une section qui a une sous-navigation (Conception, Calendrier, Suivi, Évaluations, Labo), le bouton actif reçoit la couleur d'identité de la section sur trois éléments : fond (teinté via multiply), bordure, icône SVG et label texte. La sous-nav active hérite de la même couleur. Accueil et Aperçu (sections plates) restent en blanc translucide neutre. Boutons header aide et réglages = même technique mais en jaune.

Technique CSS : background-blend-mode: multiply sur deux couches — (1) la couleur de section en opaque + (2) la couleur médiane du bandeau (--bg-bandeau-mediane, variable qui change automatiquement entre mode sombre et mode clair). Le bandeau parent garde son vrai gradient ; le bouton actif est uniforme à l'intérieur, pas de mini-gradient désaligné.

Pattern type (Conception, mode sombre) : 

.navigation-principale button[data-onglet="conception"].actif {
    background:
      linear-gradient(rgba(255, 111, 0, 1), rgba(255, 111, 0, 1)),
      linear-gradient(var(--bg-bandeau-mediane), var(--bg-bandeau-mediane));
    background-blend-mode: multiply;
    border-color: var(--section-conception);
}

Audit chromatique : plans de travail/AUDIT-COULEURS-SECTIONS.md — tous AA WCAG ou AA large (icônes). Daltonisme : Suivi/Évaluations sont indistinguables en protanopie/tritanopie ; mitigé par le label texte toujours visible (WCAG 1.4.1 conforme par double signal).
Référentiel visuel : plans de travail/REFERENTIEL-COULEURS-SECTIONS.html.

10. Alertes et badges

4 types d'alertes, badges d'évaluation et badges de notation.

La grammaire des bandeaux d'import — ce que la couleur PROMET

Fixée par Grégoire le 1er septembre 2026, après que la question « de quelle couleur ce bandeau ? » soit revenue une fois de trop. Elle ne décrit pas une intensité mais une conséquence sur les données : c'est ce qui la rend déductible plutôt qu'affaire de goût.

CouleurCe qu'elle prometExemple vivant
Bleu Informatif — rien n'est perdu. .travaux-bandeau-sans-da — pas de DA, mais l'élève est trouvé par son nom ; seul le regroupement multi-pages ne se fait pas.
Orange Le fichier n'ira pas où je crois, mais rien n'est détruit et je peux passer outre. .travaux-bandeau-autre-gc, .travaux-bandeau-da-inconnu — l'import se fait, le fichier atterrit ailleurs que prévu.
Rouge Quelque chose peut être ÉCRASÉ. .travaux-bandeau-doublon — un fichier déjà importé pour le même couple élève + production.

⚠ Un bandeau neuf se déduit de cette table, il ne se choisit pas. Et il n'est pas fini tant que sa classe n'existe pas dans styles.css : les bancs de test lisent le DOM et le texte, jamais le rendu — une classe employée sans être définie leur est invisible (voir #679).

Convention : 📔 (guidage)

Emoji 📔 = guidage, documentation, processus à suivre. Utilisé pour tout élément qui guide l'utilisateur à travers une séquence d'étapes ou fournit de la documentation structurée.

Usage
  • Bouton .planif-palette-aide-btn dans la palette planification : ouvre/ferme le panneau guide flottant
  • Le panneau guide (.planif-guide-flottante) est draggable et independant de la palette
  • Fermeture via le bouton × dans la barre du panneau ou via le bouton « Terminer » en derniere page
  • Tout futur élément de guidage (tutoriel, tour guidé, documentation intégrée) doit utiliser 📔
  • Distinction : 📔 = processus/guide structuré — 💡 = conseil/astuce ponctuel

Convention : styles inline

Acceptables
  • display: none pour le pilotage JS (toggle de visibilite)
  • Layout ponctuel unique : gap, grid-template-columns, width sur un seul element
  • style="color: var(--variable)" quand la couleur vient d'une donnee dynamique
Interdits
  • Couleurs hex hardcodees (color: #ff9800) : utiliser une variable CSS ou une classe utilitaire
  • Patterns repetes 3+ fois : extraire dans une classe CSS
