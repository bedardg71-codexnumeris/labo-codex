Prochaines étapes

Si ta demande est acceptée, tu recevras un courriel à ton adresse institutionnelle contenant le lien vers l'application ainsi qu'un code d'accès personnel. Ce code te permettra de te connecter à l'application durant la phase de test.

L'application est gratuite et personne n'a accès à tes données : elles sont stockées localement dans ton navigateur.

⚠️ Important : Tes données peuvent être perdues si tu effaces l'historique de navigation (avec l'option « données de sites »), si tu utilises la navigation privée, ou si tu changes de navigateur. Exporte régulièrement tes données via le menu Réglages → Import/Export.
