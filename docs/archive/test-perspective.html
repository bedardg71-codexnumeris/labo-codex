Banc de test — Auto-detection perspective

Procedure d'utilisation

1. Alimenter le corpus

  • Glisser-deposer des photos d'eleves dans la zone en haut a gauche
  • Chaque image est sauvegardee dans IndexedDB (persistant)
  • Ajouter des tags de conditions (ombre-laterale, sous-expose, etc.)

2. Detecter les coins

  • Selectionner une image dans la liste a gauche
  • Cliquer Detecter — les coins bleus apparaissent
  • Les 6 etapes de la pipeline s'affichent en bas (Canny, Hough, etc.)
  • Le log de la pipeline est visible en bas a droite

3. Etiqueter les coins corrects

  • Cliquer Mode etiquette (le bouton devient vert)
  • Deplacer les poignees vertes vers les vrais coins du document
  • La zone grise autour de l'image permet de placer des coins hors-cadre
  • Cliquer Valider coins pour sauvegarder l'etiquette
  • Reinit coins recopie les coins detectes (bleus) comme point de depart

4. Executer le banc de test

  • Etiqueter au moins quelques images (idealement 10-20+)
  • Cliquer Executer le banc de test
  • Chaque image etiquetee est re-detectee avec les parametres courants
  • Resultats : score global, erreur moyenne, detail par condition

5. Iterer sur l'algorithme

  • Modifier les parametres dans le panneau de droite
  • Re-executer le banc → comparer le score
  • Score monte → garder le changement
  • Score baisse → revenir aux valeurs precedentes
  • Exporter le corpus pour le sauvegarder en fichier JSON

Codes couleur

  • Bleu = coins detectes par l'algorithme
  • Vert = coins corrects (etiquettes manuelles)
  • Erreur < 0.03 → OK
  • Erreur 0.03–0.08 → Imprecis
  • Erreur > 0.08 → Echec
