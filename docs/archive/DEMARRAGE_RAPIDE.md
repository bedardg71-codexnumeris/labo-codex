# 🚀 Démarrage rapide - Monitorage Beta 91.1

**Temps requis**: 5 minutes ⏱️

---

## Étape 1 : Ouvrir l'application (30 secondes)

1. Décompressez `Monitorage_Beta_91.1.zip`
2. **Double-cliquez** sur `index 91.html`
3. L'application s'ouvre dans votre navigateur par défaut

**Astuce** : Ajoutez `index 91.html` à vos favoris pour y accéder rapidement

---

## Étape 2 : Charger les données de démonstration (1 minute)

1. Cliquez sur **Réglages** (menu gauche)
2. Cliquez sur **Import/Export**
3. Section «Importer les données» :
   - Cliquez sur **«📥 Sélectionner un fichier»**
   - Choisissez `donnees-demo.json`
   - Cliquez sur **«Importer»**
4. Confirmez en cliquant sur **«Oui, importer»**

✅ **Succès** : Message de confirmation affiché

---

## Étape 3 : Charger votre pratique (2 minutes) 🆕

**Si votre pratique est dans cette liste**, chargez-la en 2 clics :
- Bruno V. (Chimie) - PAN-Standards 5 niveaux
- Marie-Hélène L. (Littérature) - Sommative traditionnelle

- Michel B. (Mathématiques) - PAN-Objectifs pondérés
- Jordan R. (Philosophie) - Sommative + remplacement
- Isabelle M. (Biologie) - PAN-Jugement global

**Procédure** :
1. Restez dans **Réglages** (déjà ouvert)
2. Cliquez sur **Pratique de notation**
3. Cliquez sur le bouton vert **«🎯 Exemples de pratiques»**
4. **Cochez** votre pratique dans la liste
5. Cliquez sur **«Charger les pratiques sélectionnées»**
6. Attendez le message «✅ Pratique chargée avec succès»
7. Fermez le modal (X en haut à droite)
8. Dans le menu déroulant «Pratique active», **sélectionnez votre pratique**
9. Cliquez sur **«Sauvegarder»**

✅ **Succès** : Message «Configuration sauvegardée»

---

## Étape 4 : Explorer l'application (2 minutes)

### Tableau de bord
1. Cliquez sur **Tableau de bord** (menu gauche)
2. Cliquez sur **Aperçu**
3. **Observez** :
   - Les 4 sections : Indicateurs globaux, Engagement, Patterns, RàI
   - Les nuages de points avec gradients colorés
   - Les valeurs selon votre pratique chargée

### Profil d'un étudiant
1. Cliquez sur **Étudiants** (menu gauche)
2. Cliquez sur **Liste des étudiants**
3. **Cliquez sur un nom** (ex: Alya Benali)
4. **Explorez** les 3 sections :
   - Suivi de l'apprentissage
   - Développement des habiletés (affichage selon votre pratique)
   - Engagement (assiduité, complétion, artefacts)

## 🆘 Problème ?

**Erreur au chargement des données de démo** :
- Vérifiez que `donnees-demo.json` est dans le même dossier que `index 91.html`
- Rechargez la page (F5 ou Cmd+R) et recommencez

**Pratique non chargée** :
- Vérifiez que le message «✅ Pratique chargée avec succès» s'est affiché
- Vérifiez que vous avez bien sélectionné la pratique dans le menu déroulant
- Cliquez sur «Sauvegarder»

**Autres problèmes** :
- Email : labo@codexnumeris.org
- Consultez `GUIDE_TESTEURS.md` section FAQ
