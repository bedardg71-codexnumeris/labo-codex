# Guide de Labo Codex

Ce guide s'adresse à quiconque reprend Labo Codex sans son auteur : un **développeur** qui ne
connaît pas la pédagogie, un **pédagogue** qui répond de l'application sans connaître le code,
et le **cégep** qui l'héberge et en confie la maintenance.

Il dit ce qui est vrai maintenant, et pourquoi. L'historique du projet (journaux de session,
plans, rapports) reste dans le dépôt comme archive ; il n'est pas nécessaire pour comprendre
l'application.
