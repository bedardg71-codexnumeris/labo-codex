 Tâche 6 — #200 + #197 : Unifier cours et documenter namespacing

 #200 — Unifier listeCours/cours

 Décision : listeCours et cours restent globales (bibliothèque partagée). On unifie
 en gardant cours comme clé canonique (nom plus court, convention Beta 95.2).

 Fichier : js/trimestre-v2.js

 Dans chargerDropdownCoursV2() (~ligne 1290) : supprimer la fusion manuelle et ne
 lire que cours. Ajouter migration one-shot :
 // Migration : fusionner listeCours → cours (one-shot)
 const listeCours = db.getSync('listeCours', []);
 if (listeCours.length > 0) {
     const coursExistants = db.getSync('cours', []);
     const coursMap = new Map(coursExistants.map(c => [c.id, c]));
     listeCours.forEach(c => { if (c.id && !coursMap.has(c.id)) coursMap.set(c.id,
 c); });
     db.setSync('cours', Array.from(coursMap.values()));
     db.setSync('listeCours', []); // Vider l'ancienne clé
 }

 Ensuite, dans tout trimestre-v2.js, remplacer les ~15 lectures
 db.getSync('listeCours', []) et les fusions par db.getSync('cours', []).
