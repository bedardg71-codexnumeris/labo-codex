Qu’est-ce que c’est ?
Monitorage Pédagogique est une application web mono-page (SPA) de suivi de l’apprentissage pour le réseau collégial québécois (cégeps). Développée par Grégoire Bédard, enseignant, elle permet de :
	1.	Détecter précocement les étudiants à risque
	2.	Intervenir de façon ciblée selon le modèle RaI (Réponse à l’Intervention, niveaux 1-2-3)
	3.	Suivre l’efficacité des interventions
	4.	S’adapter à différentes pratiques pédagogiques (PAN-Maîtrise, Sommative, PAN-Standards)
Ce n’est PAS un système de notation traditionnel. C’est un système de détection et d’intervention préventive.

Stack technique
	∙	HTML5 / CSS3 / JavaScript ES6+ pur — aucun framework, aucune dépendance externe sauf Chart.js (graphiques)
	∙	Fonctionnement 100% hors-ligne — pas de serveur, pas de backend

	∙	SPA monolithique : un seul index.html (18 358 lignes), un seul styles.css (21 146 lignes), 90 modules JavaScript (~160 000 lignes au total)
Architecture fondamentale
Hiérarchie conceptuelle (sacrée)

—

TRIMESTRE (conteneur temporel : A2025, H2026)
    └── COURS (conteneur pédagogique : 601-101, 601-102)
        └── GROUPE (cohorte : 01, 02, 9999-démo)
            └── ÉTUDIANTS + PRODUCTIONS + ÉVALUATIONS
—

Principes architecturaux
	1.	Single Source of Truth — Chaque donnée a UNE source qui la génère. Tous les autres modules lisent, ne recalculent jamais. Un étudiant ne peut pas avoir deux moyennes différentes.
	2.	Namespacing par trimestre — Les données sont préfixées par trimestre (h2026_groupeEtudiants, a2025_presences) via le helper window.cle('nomCle'). Isolation absolue entre contextes.
	3.	Communication indirecte — Les modules ne se parlent JAMAIS directement. Communication via localStorage/IndexedDB uniquement.
	4.	Délégation aux pratiques — Le calcul des indices dépend de la pratique de notation configurée, via l’interface IPratique. L’application s’adapte à chaque enseignant.
	5.	Pattern Bibliothèque + Assemblage — Entités réutilisables (non namespacées) assemblées pour un contexte spécifique.
Flux de données

—

1. ENTRÉE      → Prof configure : trimestre + cours + groupe + productions
2. SUIVI       → Prof saisit : présences (indice A), évalue productions (notes IDME)
3. CALCUL AUTO → Système génère : indices C (complétion), P (performance)
4. DIAGNOSTIC  → Système combine A-C-P → Engagement, détecte patterns de risque
5. INTERVENTION→ Prof consulte diagnostics, agit selon niveau RaI identifié
