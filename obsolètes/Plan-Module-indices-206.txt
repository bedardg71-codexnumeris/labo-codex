 Plan — Module indices.js (#206) : centralisation des fonctions d'indices

 Contexte

 L'audit qualité (28 fév 2026) a identifié 7 fonctions de calcul d'indices A-C-P-E
 dupliquées ou dispersées entre 5 fichiers. L'item #206 demande de les regrouper dans
  un nouveau js/indices.js. Approche choisie : extraction pure — déplacer les
 fonctions telles quelles, sans modification de logique.

 ---
 Étape 1 — Créer js/indices.js

 Nouveau fichier IIFE contenant les 7 fonctions extraites. Aucune modification de
 logique.

 js/indices.js (~200 lignes)
 ├── calculerCorrelationPearson(x, y)        — utilitaire pur
 ├── determinerNiveauEngagement(engagement)  — utilitaire pur
 ├── obtenirIndicesCP(da, pratique)          — getter SST (lit indicesCP)
 ├── obtenirHistoriqueIndicesCP(da, pratique)— getter SST (lit indicesCP)
 ├── calculerPerformancePAN(da)              — fallback P (lit evaluations,
 portfolios)
 ├── calculerTousLesIndices(da, pratique)    — lecteur composite (lit A + C/P/E)
 ├── calculerIndicesEtudiant(da, cA, cCP)   — lecteur composite (SOM/PAN)
 └── exports window.*

 Dépendances externes (fonctions globales attendues par indices.js) :
 - obtenirDonneesSelonMode(cle) — modes.js (chargé avant)
 - db.getSync(cle, defaut) — db.js (chargé avant)
 - cle(nom) — window.cle, défini dans modes.js
 - calculerTauxCompletion(da) — etudiants.js (chargé après, mais appelé seulement
 dans fallback de calculerTousLesIndices, protégé par typeof)

 Exports window (mêmes noms qu'aujourd'hui) :
 window.calculerCorrelationPearson = calculerCorrelationPearson;
 window.determinerNiveauEngagement = determinerNiveauEngagement;
 window.obtenirIndicesCP = obtenirIndicesCP;
 window.obtenirHistoriqueIndicesCP = obtenirHistoriqueIndicesCP;
 window.calculerPerformancePAN = calculerPerformancePAN;
 window.calculerTousLesIndices = calculerTousLesIndices;
 window.calculerIndicesEtudiant = calculerIndicesEtudiant;

 Position : Après saisie-presences.js (ligne 17062), avant tableau-bord-apercu.js
 (ligne 17065).

 <script src="js/tableau-bord-apercu.js?v=2025122801"></script>

 Justification : indices.js dépend de modes.js et db.js (déjà chargés). Il est
 utilisé par tableau-bord-apercu.js, profil-etudiant.js, etudiants.js (chargés
 après).

 Note : calculerTousLesIndices appelle calculerTauxCompletion (etudiants.js, chargé
 après), mais ce chemin est protégé par typeof calculerTauxCompletion === 'function'
 — même pattern qu'aujourd'hui.

 Certains appelants vérifient typeof obtenirIndicesCP === 'function' avant l'appel.

 fonction existe). Aucun changement nécessaire — les guards sont un filet de sécurité
  valide.
